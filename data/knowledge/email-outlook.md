# Email and Outlook Support

Northstar employees use Microsoft 365 for email and calendaring.

Basic troubleshooting:
1. Check whether Outlook on the web works before changing desktop client settings.
2. Restart Outlook and verify the device has a working network connection.
3. For missing calendar invites, check focused inbox, junk mail, and delegate mailbox rules.
4. For repeated sign-in prompts, check identity service status and refresh the Okta session.
5. Create a ticket after confirmation if email is unavailable during a customer-impacting event.

Do not request passwords or ask employees to disable security controls.
